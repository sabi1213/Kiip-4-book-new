সরকারি নোটিশ যাচাই এবং মালিকের জন্য private traffic stats

🔒 শুধু মালিক/অনুমতিপ্রাপ্ত repository user-এর জন্য ভিজিট পরিসংখ্যান

GitHub Pages নিজেই সাম্প্রতিক ১৪ দিনের views ও unique visitors-এর aggregate পরিসংখ্যান রাখে। নিচের লিংকে গিয়ে GitHub account-এ sign in করুন:

GitHub Insights → Traffic পরিসংখ্যান খুলুন ↗

গোপনীয়তা: পরিসংখ্যান দেখতে repository-তে প্রয়োজনীয় access থাকতে হবে। অন্যদের access না দিলে তারা GitHub-এ এই traffic report দেখতে পারবে না। Site-এর public page-এ stats দেখানো হয় না.

সীমাবদ্ধতা: GitHub aggregate সংখ্যা দেখায়; কোন ব্যক্তি/নাম ওয়েবসাইটে এসেছে তা দেখায় না। Repository-তে যাদের পর্যাপ্ত permission আছে, তারাও traffic report দেখতে পারে—শুধু আপনার account-কে access দিন। GitHub traffic সাধারণত ১৪ দিনের তথ্য দেখায়।

এই লিংক শুধু private GitHub report খোলে; আমরা কোনো GitHub password/token সাইটে রাখি না।

সরকারি নোটিশ দেখুন

সরকারি নিয়ম বদলাতে পারে—নিজের visa category ও পরিস্থিতির জন্য কর্তৃপক্ষের সর্বশেষ নির্দেশনাই যাচাই করবেন।

নোটিশ দেখার ব্যক্তিগত reminder

এটি প্রতিদিন নির্দিষ্ট সময়ে সরকারি সাইট নিজে দেখে নেওয়ার reminder। এটি নতুন সরকারি notice শনাক্ত করে না; reminder কাজ করতে এই পেজ খোলা থাকতে হবে। Browser notification অনুমতি লাগবে।

সীমাবদ্ধতা: Page/browser বন্ধ থাকলে reminder নাও চলতে পারে। Automatic government push alert এখানে চালু নেই।

কোন কোন বিষয়ে খেয়াল রাখবেন?

ভিসা ও অবস্থান
নিজের visa category-এর মেয়াদ, extension ও প্রয়োজনীয় কাগজ Hi Korea-র নির্দেশনায় মিলিয়ে নিন।
ঠিকানা/বিদেশি নিবন্ধন

KIIP ও পরীক্ষা
রেজিস্ট্রেশন, ক্লাস, মূল্যায়ন ও পরীক্ষার সময়সূচি কর্তৃপক্ষের ঘোষণায় যাচাই করুন।
