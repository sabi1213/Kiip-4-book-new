Install App

অ্যাপটি হোম স্ক্রিনে যোগ করে সহজে পড়ুন। এটি একটি Progressive Web App (PWA), APK নয়।

Android · Chrome
Install App চাপুন। অপশন না এলে Chrome-এর ⋮ menu → “Install app” বা “Add to Home screen” বেছে নিন।
iPhone / iPad · Safari
Safari-তে ওয়েবসাইট খুলে Share → “Add to Home Screen” → Add চাপুন।
PC · Chrome / Edge
অ্যাড্রেস বারের Install আইকন অথবা browser menu → “Install this site as an app” নির্বাচন করুন।

বন্ধুদের সঙ্গে শেয়ার করুন

মালিকের নিয়ন্ত্রণ

মূল অধ্যায়ের কনটেন্ট repository-তে মালিকের পরিবর্তনের মাধ্যমে নিয়ন্ত্রিত। Static website-এ browser-side password নিরাপদ admin login নয়; তাই অনিরাপদ admin panel ব্যবহার করা হয়নি।
